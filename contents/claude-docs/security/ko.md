### 내장된 보호 기능

- **샌드박스 bash 도구**: 파일 시스템 및 네트워크 격리로 bash 명령을 [샌드박스](/docs/en/sandboxing)하여 보안을 유지하면서 권한 프롬프트를 줄입니다. `/sandbox`로 활성화하여 Claude Code가 자율적으로 작업할 수 있는 경계를 정의하세요
- **쓰기 접근 제한**: Claude Code는 시작된 폴더와 그 하위 폴더에만 쓸 수 있습니다. 명시적 권한 없이 상위 디렉터리의 파일을 수정할 수 없습니다. Claude Code는 작업 디렉터리 외부의 파일을 읽을 수 있지만(시스템 라이브러리 및 종속성에 접근하는 데 유용), 쓰기 작업은 프로젝트 범위로 엄격하게 제한되어 명확한 보안 경계를 만듭니다
- **프롬프트 피로 완화**: 사용자별, 코드베이스별 또는 조직별로 자주 사용하는 안전한 명령을 허용 목록에 추가 지원
- **편집 수락 모드**: 부작용이 있는 명령에 대한 권한 프롬프트를 유지하면서 여러 편집을 일괄 수락

## 프롬프트 인젝션으로부터 보호

### 핵심 보호 기능

- **권한 시스템**: 민감한 작업에는 명시적 승인 필요
- **컨텍스트 인식 분석**: 전체 요청을 분석하여 잠재적으로 유해한 지침 감지
- **입력 정제**: 사용자 입력을 처리하여 명령 인젝션 방지
- **명령 차단 목록**: 기본적으로 `curl` 및 `wget`과 같이 웹에서 임의 콘텐츠를 가져오는 위험한 명령 차단. 명시적으로 허용된 경우 [권한 패턴 제한 사항](/docs/en/iam#tool-specific-permission-rules)에 유의하세요

### 개인 정보 보호 장치

- 민감한 정보에 대한 제한된 보존 기간 (자세한 내용은 [개인정보 보호 센터](https://privacy.anthropic.com/en/articles/10023548-how-long-do-you-store-my-data) 참조)
- 사용자 세션 데이터에 대한 제한된 접근
- 데이터 학습 기본 설정에 대한 사용자 제어. 소비자 사용자는 언제든지 [개인정보 설정](https://claude.ai/settings/privacy)을 변경할 수 있습니다.

### 추가 보호 장치

- **네트워크 요청 승인**: 기본적으로 네트워크 요청을 수행하는 도구는 사용자 승인 필요
- **격리된 컨텍스트 윈도우**: Web fetch는 잠재적으로 악의적인 프롬프트 인젝션을 방지하기 위해 별도의 컨텍스트 윈도우 사용
- **신뢰 검증**: 처음 코드베이스 실행 및 새 MCP 서버에는 신뢰 검증 필요

참고: `-p` 플래그로 비대화형으로 실행할 때 신뢰 검증은 비활성화됩니다
- 참고: `-p` 플래그로 비대화형으로 실행할 때 신뢰 검증은 비활성화됩니다
- **명령 인젝션 감지**: 의심스러운 bash 명령은 이전에 허용 목록에 추가되었더라도 수동 승인 필요
- **실패 시 닫힘 일치**: 일치하지 않는 명령은 기본적으로 수동 승인 필요
- **자연어 설명**: 복잡한 bash 명령에는 사용자 이해를 위한 설명 포함
- **안전한 자격 증명 저장**: API 키와 토큰은 암호화됨. [자격 증명 관리](/docs/en/iam#credential-management) 참조

> **Windows WebDAV 보안 위험**: Windows에서 Claude Code를 실행할 때 WebDAV를 활성화하거나 WebDAV 하위 디렉터리를 포함할 수 있는 `\\*`와 같은 경로에 Claude Code가 접근하도록 허용하지 않는 것을 권장합니다. [WebDAV는 Microsoft에서 보안 위험으로 인해 더 이상 사용되지 않습니다](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features#:~:text=The%20Webclient%20(WebDAV)%20service%20is%20deprecated). WebDAV를 활성화하면 Claude Code가 권한 시스템을 우회하여 원격 호스트에 대한 네트워크 요청을 트리거할 수 있습니다.

- 승인 전에 제안된 명령 검토
- 신뢰할 수 없는 콘텐츠를 Claude에 직접 파이프하지 않기
- 중요한 파일에 대한 제안된 변경 사항 확인
- 외부 웹 서비스와 상호 작용할 때 특히 스크립트를 실행하고 도구를 호출하기 위해 가상 머신(VM) 사용
- `/bug`로 의심스러운 동작 보고

> 이러한 보호 기능은 위험을 크게 줄이지만, 어떤 시스템도 모든 공격에
> 완전히 면역되지는 않습니다. 모든 AI 도구로 작업할 때
> 항상 좋은 보안 관행을 유지하세요.

## 클라우드 실행 보안

- **격리된 가상 머신**: 각 클라우드 세션은 Anthropic이 관리하는 격리된 VM에서 실행
- **네트워크 접근 제어**: 네트워크 접근은 기본적으로 제한되며 비활성화하거나 특정 도메인만 허용하도록 구성 가능
- **자격 증명 보호**: 인증은 샌드박스 내에서 범위가 지정된 자격 증명을 사용하는 안전한 프록시를 통해 처리되며, 이는 실제 GitHub 인증 토큰으로 변환됨
- **브랜치 제한**: Git push 작업은 현재 작업 브랜치로 제한
- **감사 로깅**: 클라우드 환경에서의 모든 작업은 규정 준수 및 감사 목적으로 기록
- **자동 정리**: 클라우드 환경은 세션 완료 후 자동으로 종료

## 보안 모범 사례

### 민감한 코드 작업

- 승인 전에 모든 제안된 변경 사항 검토
- 민감한 저장소에 대해 프로젝트별 권한 설정 사용
- 추가 격리를 위해 [devcontainers](/docs/en/devcontainer) 사용 고려
- `/permissions`로 권한 설정을 정기적으로 감사

### 팀 보안

- [엔터프라이즈 관리 설정](/docs/en/iam#enterprise-managed-settings)을 사용하여 조직 표준 시행
- 버전 관리를 통해 승인된 권한 구성 공유
- 보안 모범 사례에 대해 팀원 교육
- [OpenTelemetry 메트릭](/docs/en/monitoring-usage)을 통해 Claude Code 사용량 모니터링

### 보안 문제 보고

- 공개적으로 공개하지 마세요
- [HackerOne 프로그램](https://hackerone.com/anthropic-vdp/reports/new?type=team&report_type=vulnerability)을 통해 보고
- 자세한 재현 단계 포함
- 공개 전에 문제를 해결할 시간 허용
