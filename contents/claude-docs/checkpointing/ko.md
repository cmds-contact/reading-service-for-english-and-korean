# 체크포인팅

Claude의 편집을 자동으로 추적하고 되감아 원치 않는 변경 사항에서 빠르게 복구합니다.

## 체크포인트 작동 방식

### 자동 추적

- 모든 사용자 프롬프트가 새 체크포인트를 생성합니다
- 체크포인트는 세션 간에 유지되므로 재개된 대화에서 접근할 수 있습니다
- 30일 후 세션과 함께 자동으로 정리됩니다 (설정 가능)

### 변경 사항 되감기

- **대화만**: 코드 변경을 유지하면서 사용자 메시지로 되감기
- **코드만**: 대화를 유지하면서 파일 변경 되돌리기
- **코드와 대화 모두**: 세션의 이전 시점으로 둘 다 복원

## 일반적인 사용 사례

- **대안 탐색**: 시작점을 잃지 않고 다양한 구현 방식 시도
- **실수 복구**: 버그를 도입하거나 기능을 망가뜨린 변경 사항을 빠르게 취소
- **기능 반복**: 작동하는 상태로 되돌릴 수 있다는 것을 알고 변형 실험

## 제한 사항

### Bash 명령어 변경은 추적되지 않음

```
rm file.txt
mv old.txt new.txt
cp source.txt dest.txt
```

### 외부 변경은 추적되지 않음

### 버전 관리를 대체하지 않음

- 커밋, 브랜치, 장기 기록을 위해 버전 관리(예: Git) 계속 사용
- 체크포인트는 적절한 버전 관리를 보완하지만 대체하지 않음
- 체크포인트를 "로컬 실행 취소"로, Git을 "영구 기록"으로 생각하세요
