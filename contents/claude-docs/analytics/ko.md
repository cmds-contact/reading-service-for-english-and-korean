# 분석

조직의 Claude Code 배포에 대한 상세한 사용 인사이트와 생산성 메트릭을 확인하세요.

> 분석은 현재 Claude Console을 통해 Claude API와 함께 Claude Code를 사용하는 조직에서만 사용할 수 있습니다.

## 분석 접근

### 필수 역할

- **Primary Owner**
- **Owner**
- **Billing**
- **Admin**
- **Developer**

> **User**, **Claude Code User** 또는 **Membership Admin** 역할을 가진 사용자는 분석에 접근할 수 없습니다.

## 사용 가능한 메트릭

### 수락된 코드 라인

- 거부된 코드 제안은 제외
- 이후 삭제는 추적하지 않음

### 제안 수락률

- Edit
- Write
- NotebookEdit

### 활동

### 지출

### 팀 인사이트

- API 키 사용자는 **API 키 식별자**로 표시됩니다
- OAuth 사용자는 **이메일 주소**로 표시됩니다

## 분석 효과적으로 사용하기

### 채택 현황 모니터링

- 모범 사례를 공유할 수 있는 활성 사용자
- 조직 전반의 전체적인 채택 추세

### 생산성 측정

- Claude Code 제안에 대한 개발자 만족도 이해
- 코드 생성 효율성 추적
- 교육 또는 프로세스 개선 기회 파악
