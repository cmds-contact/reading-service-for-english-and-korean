# 데이터 사용

Claude에 대한 Anthropic의 데이터 사용 정책에 대해 알아봅니다

## 데이터 정책

### 데이터 학습 정책

- 현재 사용자인 경우 지금 기본 설정을 선택할 수 있으며 선택이 즉시 적용됩니다.
이 설정은 Claude의 새 채팅 또는 재개된 채팅 및 코딩 세션에만 적용됩니다. 추가 활동이 없는 이전 채팅은 모델 학습에 사용되지 않습니다.
- 2025년 10월 8일까지 선택을 완료해야 합니다.
신규 사용자인 경우 가입 과정에서 모델 학습 설정을 선택할 수 있습니다.
개인정보 설정에서 언제든지 선택을 변경할 수 있습니다.

### 세션 품질 설문조사

### 데이터 보존

- 모델 개선을 위한 데이터 사용을 허용하는 사용자: 모델 개발 및 안전성 개선을 지원하기 위한 5년 보존 기간
- 모델 개선을 위한 데이터 사용을 허용하지 않는 사용자: 30일 보존 기간
- 개인정보 설정은 [claude.ai/settings/data-privacy-controls](https://claude.ai/settings/data-privacy-controls)에서 언제든지 변경할 수 있습니다.
- 표준: 30일 보존 기간
- 제로 데이터 보존: 적절하게 구성된 API 키로 사용 가능 - Claude Code는 서버에 채팅 기록을 보존하지 않음
- 로컬 캐싱: Claude Code 클라이언트는 세션 재개를 활성화하기 위해 최대 30일 동안 로컬에 세션을 저장할 수 있음 (구성 가능)

## 데이터 흐름 및 종속성

### 클라우드 실행

> 위의 데이터 흐름 다이어그램 및 설명은 로컬 머신에서 실행되는 Claude Code CLI에 적용됩니다. 웹에서 Claude Code를 사용하는 클라우드 기반 세션의 경우 아래 섹션을 참조하세요.

- **코드 저장**: 저장소가 격리된 VM에 복제되고 세션 완료 후 자동으로 삭제됨
- **자격 증명**: GitHub 인증은 안전한 프록시를 통해 처리됨; GitHub 자격 증명은 샌드박스에 들어가지 않음
- **네트워크 트래픽**: 모든 아웃바운드 트래픽은 감사 로깅 및 남용 방지를 위해 보안 프록시를 통과
- **데이터 보존**: 코드 및 세션 데이터는 계정 유형에 대한 보존 및 사용 정책의 적용을 받음
- **세션 데이터**: 프롬프트, 코드 변경 및 출력은 로컬 Claude Code 사용과 동일한 데이터 정책을 따름
