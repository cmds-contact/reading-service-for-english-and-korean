# Slack에서 Claude Code 사용하기

Slack 워크스페이스에서 직접 코딩 작업을 위임하세요

## 사용 사례

- **버그 조사 및 수정**: Slack 채널에 버그가 보고되면 Claude에게 즉시 조사하고 수정하도록 요청하세요.
- **빠른 코드 리뷰 및 수정**: 팀 피드백을 기반으로 Claude가 작은 기능을 구현하거나 코드를 리팩토링하도록 하세요.
- **협업 디버깅**: 팀 논의에서 중요한 컨텍스트(예: 오류 재현 또는 사용자 보고)를 제공하면 Claude가 해당 정보를 활용하여 디버깅 접근 방식을 결정할 수 있습니다.
- **병렬 작업 실행**: 다른 작업을 계속하면서 Slack에서 코딩 작업을 시작하고, 완료되면 알림을 받으세요.

## Slack에서 Claude Code 설정하기

Slack에 Claude 앱 설치

Claude 계정 연결

- Apps 섹션에서 "Claude"를 클릭하여 Slack에서 Claude 앱 열기
- App Home 탭으로 이동
- "Connect"를 클릭하여 Slack 계정을 Claude 계정과 연결
- 브라우저에서 인증 흐름 완료

웹에서 Claude Code 구성

- Slack에 연결한 것과 동일한 계정으로 [claude.ai/code](https://claude.ai/code)에 방문하여 로그인
- 아직 연결되지 않은 경우 GitHub 계정 연결
- Claude가 작업할 저장소를 하나 이상 인증

라우팅 모드 선택

> Code + Chat 모드에서 Claude가 메시지를 Chat으로 라우팅했지만 코딩 세션을 원했다면 "Retry as Code"를 클릭하여 대신 Claude Code 세션을 생성할 수 있습니다. 마찬가지로 Code로 라우팅되었지만 Chat 세션을 원했다면 해당 스레드에서 해당 옵션을 선택할 수 있습니다.

## 작동 방식

### 자동 감지

> Slack에서 Claude Code는 채널(공개 또는 비공개)에서만 작동합니다. DM(다이렉트 메시지)에서는 작동하지 않습니다.

### 컨텍스트 수집

> @Claude가 Slack에서 호출되면 Claude는 요청을 더 잘 이해하기 위해 대화 컨텍스트에 액세스합니다. Claude는 컨텍스트의 다른 메시지에서 지시를 따를 수 있으므로, 사용자는 신뢰할 수 있는 Slack 대화에서만 Claude를 사용해야 합니다.

### 세션 흐름

- **시작**: 코딩 요청으로 Claude를 @멘션
- **감지**: Claude가 메시지를 분석하고 코딩 의도 감지
- **세션 생성**: claude.ai/code에 새 Claude Code 세션 생성
- **진행 업데이트**: 작업이 진행됨에 따라 Claude가 Slack 스레드에 상태 업데이트 게시
- **완료**: 완료되면 Claude가 요약과 액션 버튼과 함께 @멘션
- **검토**: "View Session"을 클릭하여 전체 기록 보기, 또는 "Create PR"을 클릭하여 풀 리퀘스트 열기

### 메시지 액션

- **View Session**: 수행된 모든 작업을 볼 수 있고, 세션을 계속하거나 추가 요청을 할 수 있는 브라우저에서 전체 Claude Code 세션을 엽니다.

- **Change Repo**: Claude가 잘못된 저장소를 선택한 경우 다른 저장소를 선택할 수 있습니다.

## 모범 사례

### 효과적인 요청 작성

- **구체적으로 작성**: 관련될 때 파일 이름, 함수 이름, 오류 메시지를 포함하세요.
- **컨텍스트 제공**: 대화에서 명확하지 않은 경우 저장소나 프로젝트를 언급하세요.
- **성공 정의**: "완료"가 어떤 모습인지 설명하세요. Claude가 테스트를 작성해야 하나요? 문서를 업데이트해야 하나요? PR을 생성해야 하나요?
- **스레드 사용**: 버그나 기능에 대해 논의할 때 스레드에서 답장하여 Claude가 전체 컨텍스트를 수집할 수 있도록 하세요.

## 문제 해결

### 세션이 시작되지 않음

- Claude App Home에서 Claude 계정이 연결되어 있는지 확인
- 웹에서 Claude Code 액세스가 활성화되어 있는지 확인
- Claude Code에 연결된 GitHub 저장소가 하나 이상 있는지 확인

### 저장소가 표시되지 않음

- [claude.ai/code](https://claude.ai/code)의 웹에서 Claude Code에 저장소 연결
- 해당 저장소에 대한 GitHub 권한 확인
- GitHub 계정 연결 해제 후 다시 연결 시도

### 잘못된 저장소 선택됨

- "Change Repo" 버튼을 클릭하여 다른 저장소 선택
- 더 정확한 선택을 위해 요청에 저장소 이름 포함

### 인증 오류

- App Home에서 Claude 계정 연결 해제 후 다시 연결
- 브라우저에서 올바른 Claude 계정에 로그인되어 있는지 확인
- Claude 요금제에 Claude Code 액세스가 포함되어 있는지 확인

### 세션 만료

- 세션은 웹의 Claude Code 기록에서 계속 액세스할 수 있습니다
- [claude.ai/code](https://claude.ai/code)에서 과거 세션을 계속하거나 참조할 수 있습니다

## 현재 제한 사항

- **GitHub 전용**: 현재 GitHub의 저장소만 지원합니다.
- **한 번에 하나의 PR**: 각 세션은 하나의 풀 리퀘스트를 생성할 수 있습니다.
- **속도 제한 적용**: 세션은 개인 Claude 요금제의 속도 제한을 사용합니다.
- **웹 액세스 필요**: 사용자는 웹에서 Claude Code 액세스가 있어야 합니다. 없는 사용자는 표준 Claude 채팅 응답만 받습니다.
