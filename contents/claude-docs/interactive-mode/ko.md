## 명령어 기록

- 기록은 작업 디렉토리별로 저장됩니다
- `/clear` 명령어로 지워집니다
- 위/아래 화살표로 탐색합니다 (위의 키보드 단축키 참조)
- **참고**: 기록 확장(`!`)은 기본적으로 비활성화되어 있습니다

### Ctrl+R을 사용한 역방향 검색

- **검색 시작**: `Ctrl+R`을 눌러 역방향 기록 검색을 활성화합니다
- **쿼리 입력**: 이전 명령어에서 검색할 텍스트를 입력합니다 - 검색어는 일치하는 결과에서 강조 표시됩니다
- **일치 항목 탐색**: `Ctrl+R`을 다시 눌러 이전 일치 항목을 순환합니다
- **일치 항목 수락**:

`Tab` 또는 `Esc`를 눌러 현재 일치 항목을 수락하고 편집을 계속합니다
`Enter`를 눌러 명령어를 수락하고 즉시 실행합니다
- `Tab` 또는 `Esc`를 눌러 현재 일치 항목을 수락하고 편집을 계속합니다
- `Enter`를 눌러 명령어를 수락하고 즉시 실행합니다
- **검색 취소**:

`Ctrl+C`를 눌러 취소하고 원래 입력을 복원합니다
빈 검색에서 `Backspace`를 눌러 취소합니다
- `Ctrl+C`를 눌러 취소하고 원래 입력을 복원합니다
- 빈 검색에서 `Backspace`를 눌러 취소합니다

## 백그라운드 Bash 명령어

### 백그라운드 실행 방식

- Claude Code에게 백그라운드에서 명령어를 실행하도록 프롬프트합니다
- Ctrl+B를 눌러 일반 Bash 도구 호출을 백그라운드로 이동합니다. (Tmux 사용자는 tmux의 접두사 키 때문에 Ctrl+B를 두 번 눌러야 합니다.)
- 출력은 버퍼링되며 Claude는 BashOutput 도구를 사용하여 가져올 수 있습니다
- 백그라운드 작업에는 추적 및 출력 검색을 위한 고유 ID가 있습니다
- Claude Code가 종료되면 백그라운드 작업이 자동으로 정리됩니다
- 빌드 도구 (webpack, vite, make)
- 패키지 관리자 (npm, yarn, pnpm)
- 테스트 러너 (jest, pytest)
- 개발 서버
- 장시간 실행 프로세스 (docker, terraform)

### ! 접두사를 사용한 Bash 모드

```
! npm test
! git status
! ls -la
```

- 명령어와 출력을 대화 컨텍스트에 추가합니다
- 실시간 진행 상황과 출력을 보여줍니다
- 장시간 실행 명령어에 대해 동일한 `Ctrl+B` 백그라운드 실행을 지원합니다
- Claude가 명령어를 해석하거나 승인할 필요가 없습니다
