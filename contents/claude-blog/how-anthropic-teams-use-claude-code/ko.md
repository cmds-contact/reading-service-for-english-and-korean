Anthropic 전반의 팀들은 프로덕션 이슈 디버깅과 익숙하지 않은 코드베이스 탐색부터 맞춤형 자동화 도구 구축까지 모든 작업에 Claude Code를 사용합니다. 그 방법을 소개합니다.

[Claude Code](https://www.anthropic.com/claude-code)와 같은 에이전틱 코딩 도구는 개발자가 워크플로우를 가속화하고, 반복 작업을 자동화하며, 복잡한 프로그래밍 프로젝트를 처리하는 데 도움을 줍니다. 이 분야가 발전함에 따라 우리는 자체 직원을 포함한 사용자들로부터 매일 새로운 활용 사례를 배우고 있습니다.

더 자세히 알아보기 위해 Anthropic 전반의 직원들과 만나 그들이 업무에서 Claude Code를 어떻게 사용하는지 들어보았습니다.

그들의 사용 사례 중 많은 것이 예상 가능했습니다--디버깅, 코드베이스 탐색, 워크플로우 관리. 하지만 다른 것들은 우리를 놀라게 했습니다. 변호사들은 전화 연결 시스템을 구축했습니다. 마케터들은 몇 초 만에 수백 개의 광고 변형을 생성했습니다. 데이터 과학자들은 JavaScript를 모르면서도 복잡한 시각화를 만들었습니다.

패턴이 명확해졌습니다: 에이전틱 코딩은 단순히 전통적인 개발을 가속화하는 것이 아닙니다. 기술적 업무와 비기술적 업무 사이의 경계를 허물어, 문제를 설명할 수 있는 사람이라면 누구나 솔루션을 구축할 수 있게 만들고 있습니다.

우리가 배운 것을 소개합니다.

### 코드베이스 탐색 및 이해

회사 전반의 팀들이 Claude Code를 사용하여 신입 사원뿐만 아니라 오랜 기간 근무한 직원들도 코드베이스를 빠르게 파악할 수 있도록 돕습니다.

인프라 팀의 새로운 데이터 과학자들은 Claude Code에 전체 코드베이스를 입력하여 빠르게 생산성을 높입니다. Claude는 코드베이스의 [CLAUDE.md](http://claude.md) 파일을 읽고, 관련 파일을 식별하며, 데이터 파이프라인 의존성을 설명하고, 어떤 업스트림 소스가 대시보드에 연결되는지 보여주어 전통적인 데이터 카탈로그 도구를 대체합니다.

제품 엔지니어링 팀은 Claude Code를 모든 프로그래밍 작업의 "첫 번째 목적지"라고 부릅니다. 버그 수정, 기능 개발, 분석을 위해 어떤 파일을 검토해야 하는지 물어보며, 새로운 기능을 구축하기 전에 수동으로 컨텍스트를 수집하는 시간 소모적인 과정을 없앱니다.

### 테스트 및 코드 리뷰

에이전틱 코딩 도구는 두 가지 중요하지만 지루한 프로그래밍 작업인 단위 테스트 작성과 코드 리뷰를 자동화하는 능력으로 특히 인기가 있습니다.

제품 디자인 팀은 Claude Code를 사용하여 새로운 기능에 대한 포괄적인 테스트를 작성합니다. GitHub Actions를 통해 Pull Request 코멘트를 자동화했으며, Claude가 포맷팅 문제와 테스트 케이스 리팩토링을 자동으로 처리합니다.

보안 엔지니어링 팀은 "설계 문서 -> 급조한 코드 -> 리팩토링 -> 테스트 포기"라는 워크플로우를 Claude에게 의사 코드를 요청하고, 테스트 주도 개발을 안내하며, 주기적으로 확인하는 방식으로 전환했습니다. 이를 통해 더 신뢰할 수 있고 테스트 가능한 코드가 만들어집니다.

에이전틱 코딩은 테스트를 다른 프로그래밍 언어로 번역하는 데도 사용할 수 있습니다. 예를 들어, 추론 팀이 Rust와 같은 익숙하지 않은 언어에서 기능을 테스트해야 할 때, 그들은 테스트하고 싶은 것을 설명하면 Claude가 코드베이스의 네이티브 언어로 로직을 작성합니다.

### 디버깅 및 문제 해결

프로덕션 이슈는 빠른 해결을 요구하지만, 압박감 속에서 익숙하지 않은 코드를 추론하려 하면 종종 지연이 발생합니다. 회사의 많은 팀에서 Claude Code는 스택 트레이스, 문서, 시스템 동작을 실시간으로 분석하여 진단과 수정을 가속화합니다.

인시던트 발생 시, 보안 엔지니어링 팀은 Claude Code에 스택 트레이스와 문서를 입력하여 코드베이스 전체의 제어 흐름을 추적합니다. 일반적으로 10-15분이 걸리는 수동 스캐닝 문제가 이제 3배 빠르게 해결됩니다.

Claude Code를 통해 제품 엔지니어링 팀은 익숙하지 않은 코드베이스의 버그를 자신 있게 처리할 수 있게 되었습니다. "이 버그를 고칠 수 있나요? 이것이 제가 보고 있는 동작입니다"라고 Claude에게 물어보고, 다른 엔지니어링 팀의 도움 없이 제안된 솔루션을 검토합니다.

한 사례에서, Kubernetes 클러스터가 파드 스케줄링을 멈췄을 때, 데이터 인프라 팀은 Claude Code를 사용하여 문제를 진단했습니다. 대시보드 스크린샷을 입력하자, Claude는 파드 IP 주소 고갈을 찾을 때까지 Google Cloud UI를 메뉴별로 안내했습니다. 그런 다음 Claude는 새 IP 풀을 생성하고 클러스터에 추가하는 정확한 명령어를 제공하여, 시스템 장애 중 20분의 귀중한 시간을 절약했습니다.

### 프로토타이핑 및 기능 개발

새로운 기능을 구축하려면 전통적으로 깊은 기술 지식과 상당한 시간 투자가 필요합니다. Claude Code는 빠른 프로토타이핑과 심지어 전체 애플리케이션 개발을 가능하게 하여, 팀이 프로그래밍 전문성에 관계없이 아이디어를 빠르게 검증할 수 있게 합니다.

제품 디자인 팀원들은 Figma 디자인 파일을 Claude Code에 입력한 다음, Claude Code가 새 기능의 코드를 작성하고, 테스트를 실행하며, 지속적으로 반복하는 자율 루프를 설정합니다. 그들은 Claude에게 추상적인 문제를 주고, 자율적으로 작업하게 한 다음, 최종 수정 전에 솔루션을 검토합니다. 한 경우에는 최소한의 인간 검토로 Claude가 자체적으로 Vim 키 바인딩을 구축하도록 했습니다.

Claude Code를 통해 제품 디자인 팀은 예상치 못한 용도를 발견했습니다: 개발 중이 아닌 디자인 단계에서 에러 상태, 로직 흐름, 시스템 상태를 매핑하여 엣지 케이스를 식별합니다. 이는 초기 디자인 품질을 근본적으로 향상시키고 나중에 몇 시간의 디버깅 시간을 절약합니다.

TypeScript에 능숙하지 않음에도 불구하고, 데이터 과학자들은 Claude Code를 사용하여 RL 모델 성능을 시각화하는 전체 React 애플리케이션을 구축합니다. 샌드박스 환경에서 원샷 프롬프팅 후, 도구는 코드 자체를 이해하지 않고도 처음부터 전체 TypeScript 시각화를 작성합니다. 작업의 단순성을 고려할 때, 첫 번째 프롬프트가 충분하지 않으면 약간의 수정을 하고 다시 시도합니다.

### 문서화 및 지식 관리

기술 문서는 종종 위키, 코드 주석, 팀원들의 머릿속에 흩어져 있습니다. Claude Code는 MCP와 CLAUDE.md 파일을 통해 이 지식을 접근 가능한 형식으로 통합하여, 필요한 모든 사람이 전문 지식을 사용할 수 있게 합니다.

ML 배경이 없는 추론 팀원들은 모델별 함수를 설명하는 데 Claude에 의존합니다. 일반적으로 한 시간의 Google 검색이 필요한 것이 이제 10-20분이 걸립니다--연구 시간이 80% 감소했습니다.

보안 엔지니어링 팀은 Claude가 여러 문서 소스를 수집하여 마크다운 런북과 문제 해결 가이드를 생성하도록 합니다. 이러한 압축된 문서는 실제 프로덕션 이슈를 디버깅하기 위한 컨텍스트가 되며, 이는 종종 전체 지식 베이스를 검색하는 것보다 더 효율적입니다.

### 자동화 및 워크플로우 최적화

에이전틱 코딩 도구는 전통적으로 전용 개발자 리소스나 비싼 소프트웨어가 필요했던 맞춤형 자동화를 팀이 구축하는 데 도움을 줍니다.

그로스 마케팅 팀은 수백 개의 광고가 포함된 CSV 파일을 처리하고, 성과가 낮은 광고를 식별하며, 엄격한 문자 수 제한 내에서 새로운 변형을 생성하는 에이전틱 워크플로우를 구축했습니다. 두 개의 전문화된 서브 에이전트를 사용하여, 시스템은 몇 시간이 아닌 몇 분 만에 수백 개의 새 광고를 생성합니다.

그들은 또한 프레임을 식별하고 헤드라인과 설명을 교체하여 최대 100개의 광고 변형을 프로그래밍 방식으로 생성하는 Figma 플러그인을 개발했습니다. 광고 배치당 몇 시간의 복사-붙여넣기가 0.5초로 줄었습니다.

특히 독특한 사용 사례에서, 법무 팀은 팀원들이 Anthropic의 적합한 변호사와 연결할 수 있도록 돕는 프로토타입 "전화 연결" 시스템을 만들었습니다. 이는 부서가 전통적인 개발 리소스 없이 맞춤형 도구를 구축할 수 있음을 보여줍니다.

### Claude Code로 새로운 가능성 열기

이러한 이야기들은 하나의 패턴을 보여줍니다: Claude Code는 그것이 증강할 수 있는 인간 워크플로우에 집중할 때 가장 잘 작동합니다. 가장 성공적인 팀들은 Claude Code를 코드 생성기가 아닌 사고 파트너로 대합니다.

그들은 가능성을 탐색하고, 빠르게 프로토타입을 만들며, 기술적 사용자와 비기술적 사용자 모두에게 발견을 공유합니다. 인간과 AI 사이의 이러한 협력적 접근 방식은 우리가 이제 막 이해하기 시작한 기회를 창출합니다.
