스킬과 MCP가 어떻게 함께 작동하여 여러분의 워크플로우를 따르고 외부 시스템과 플랫폼을 효과적으로 사용하는 에이전트를 구축하는지 알아보세요.

**업데이트:** [Agent Skills](https://agentskills.io)를 크로스 플랫폼 이식성을 위한 개방형 표준으로 발표했습니다. (2025년 12월 18일)

[Skills 출시](https://claude.com/blog/skills) 이후, 고객들로부터 가장 많이 받은 질문 두 가지는 "스킬과 MCP가 어떻게 함께 작동하나요? 언제 어떤 것을 사용해야 하나요?"입니다.

[Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro)은 Claude를 서드파티 도구에 연결하고, 스킬은 Claude가 그것들을 잘 사용하는 방법을 가르칩니다. 둘을 결합하면, 지속적인 수정이 필요한 일반적인 프로세스가 아닌 여러분 팀의 워크플로우를 따르는 에이전트를 구축할 수 있습니다.

예를 들어, Notion에 대한 MCP 연결은 Claude가 여러분의 워크스페이스를 검색할 수 있게 해줍니다. 회의 준비 스킬을 추가하면, Claude는 *어떤* 페이지에서 정보를 가져와야 하는지, *어떻게* 준비 문서를 포맷해야 하는지, 회의록 전달에 대한 팀의 표준이 *무엇*인지 알게 됩니다. 연결이 단순히 가능한 것에서 유용한 것으로 바뀝니다.

이 글에서는 스킬과 MCP의 관계, 일관된 결과물을 생성하는 워크플로우를 따르는 에이전트를 구축하기 위해 둘을 결합하는 방법, 그리고 실제로 어떻게 함께 작동하는지에 대한 몇 가지 실제 예시를 다룹니다.

## 스킬과 MCP 이해하기

여러분이 고장난 캐비닛을 고치려고 철물점에 들어간다고 상상해 보세요. 가게에는 필요한 모든 것(목공용 접착제, 클램프, 교체용 경첩)이 있지만, 어떤 물건을 사야 하고 어떻게 사용해야 하는지 아는 것은 다른 문제입니다.

MCP는 매장 통로에 접근할 수 있는 것과 같습니다. 반면 스킬은 직원의 전문 지식과 같습니다. 아무리 많은 재고가 있어도 어떤 물품이 필요하고 어떻게 사용하는지 모르면 도움이 되지 않습니다. 스킬은 수리 과정을 안내하고, 올바른 물품을 가리키며, 적절한 기술을 보여주는 도움이 되는 직원과 같습니다.

더 구체적으로 말하면, MCP 서버는 Claude에게 외부 시스템, 서비스, 플랫폼에 대한 접근 권한을 제공하고, 스킬은 Claude가 이러한 연결을 효과적으로 사용하는 데 필요한 컨텍스트를 제공하여 이제 이 접근 권한으로 무엇을 해야 하는지 가르칩니다.

스킬이 제공하는 컨텍스트 없이는 Claude가 원하는 것을 추측해야 합니다. 스킬이 있으면 Claude는 여러분의 플레이북을 따를 수 있습니다.

## 스킬과 MCP가 잘 작동하는 이유

MCP는 연결을 담당합니다: 외부 시스템에 대한 안전하고 표준화된 접근. GitHub, Salesforce, Notion 또는 자체 내부 API에 연결하든, MCP 서버는 Claude에게 도구와 데이터에 도달할 수 있는 능력을 제공합니다.

스킬은 전문성을 담당합니다: 원시 도구 접근을 신뢰할 수 있는 결과로 바꾸는 도메인 지식과 워크플로우 로직. 스킬은 언제 CRM을 쿼리해야 하는지, 결과에서 무엇을 찾아야 하는지, 출력을 어떻게 포맷해야 하는지, 어떤 예외 상황에서 다른 처리가 필요한지 알고 있습니다.

이러한 분리는 아키텍처를 조합 가능하게 유지합니다. 단일 스킬이 여러 MCP 서버를 조율할 수 있고, 단일 MCP 서버가 수십 개의 다른 스킬을 지원할 수 있습니다. 새 연결을 추가하면 기존 스킬이 이를 통합할 수 있습니다. 스킬을 개선하면 연결된 모든 도구에서 작동합니다.

#### 스킬과 MCP를 결합하면 다음을 얻을 수 있습니다:

**명확한 발견**: Claude가 어디를 봐야 하는지 추측하는 것을 멈춥니다. 회의 준비 스킬은 다음을 지정할 수 있습니다: 먼저 프로젝트 페이지를 확인하고, 그 다음 이전 회의록, 그 다음 이해관계자 프로필. 연구 스킬은 다음과 같이 말할 수 있습니다: 공유 드라이브에서 시작하고, CRM과 교차 참조한 다음, 웹 검색으로 빈틈을 채우세요. 스킬은 어떤 작업에 어떤 소스가 중요한지에 대한 조직의 지식을 인코딩합니다.

**신뢰할 수 있는 조율**: 다단계 워크플로우가 예측 가능해집니다. 스킬 없이는 Claude가 모든 것을 갖추었는지 확인하기 전에 데이터를 가져와 포맷할 수 있습니다. 스킬은 순서를 명시적으로 정의하므로 Claude는 매번 같은 방식으로 워크플로우를 실행합니다.

**일관된 성능**: 출력이 실제로 표준을 충족합니다. 일반적인 결과는 편집이 필요합니다. 스킬은 팀에게 "완료"가 어떤 모습인지 정의합니다: 올바른 구조, 올바른 세부 수준, 청중에게 적합한 톤.

시간이 지남에 따라 팀은 Claude에게 특정 도메인에 대한 전문 지식을 제공하는 상호 연관된 스킬과 연결의 컬렉션을 구축합니다.

#### 스킬과 MCP가 겹칠 수 있는 부분

MCP 서버는 일반적인 작업을 위한 도구 사용 힌트와 프롬프트 형태의 지침을 포함할 수 있습니다. 이는 도구별 지식을 도구 가까이에 유지합니다. 그러나 이러한 지침은 설계상 일반적으로 유지되어야 합니다.

경험 법칙: MCP 지침은 서버와 도구를 올바르게 사용하는 방법을 다룹니다. 스킬 지침은 주어진 프로세스나 다중 서버 워크플로우에서 어떻게 사용하는지를 다룹니다.

예를 들어, Salesforce MCP 서버는 쿼리 구문과 API 형식을 지정할 수 있습니다. 스킬은 어떤 레코드를 먼저 확인해야 하는지, 최근 컨텍스트를 위해 Slack 대화와 어떻게 교차 참조하는지, 팀의 파이프라인 검토를 위해 출력을 어떻게 구성하는지를 지정합니다.

MCP 서버와 스킬을 결합할 때 충돌하는 지침을 주의하세요. MCP 서버가 JSON을 반환하라고 하고 스킬이 마크다운 테이블로 포맷하라고 하면, Claude는 어떤 것이 맞는지 추측해야 합니다. MCP가 연결을 처리하게 하고, 스킬이 프레젠테이션, 시퀀싱, 워크플로우 로직을 처리하게 하세요.

## 스킬과 MCP를 함께 사용하는 실제 예시

이제 스킬과 MCP가 실제 워크플로우에서 어떻게 결합되는지 살펴보겠습니다. 두 가지 예시를 살펴볼 것입니다: 회사 가치 평가를 위해 실시간 시장 데이터를 가져오는 재무 분석가와 회의 준비를 위해 Notion의 Meeting Intelligence 스킬을 사용하는 프로젝트 매니저.

두 경우 모두 MCP 서버는 도구에 대한 접근을 제공하고 스킬은 그것들로 무엇을 해야 하는지 정의합니다.

#### 재무 분석: 회사 가치 평가 자동화 스킬

[Anthropic은 비교 기업 분석을 포함한 일반적인 재무 워크플로우를 위한 사전 구축된 스킬 세트를 출시했습니다](https://www.anthropic.com/news/advancing-claude-for-financial-services). 비교 기업 분석은 표준 가치 평가 방법입니다. 비교 기업 분석을 수행하는 분석가들은 여러 소스에서 재무 지표를 가져오고, 동일한 가치 평가 방법론을 적용하고, 규정 준수 표준에 맞게 출력을 포맷하는 데 몇 시간을 보냅니다. 반복적이고 오류가 발생하기 쉬우며, 스킬과 MCP가 함께 작동하면 정확히 이런 종류의 워크플로우에서 이점을 얻습니다.

**스킬**: [비교 기업 분석](https://www.anthropic.com/news/advancing-claude-for-financial-services)은 이 가치 평가 워크플로우를 자동화하여 여러 소스에서 데이터를 가져오고, 일관된 방법론을 적용하고, 특정 표준에 맞게 출력을 포맷합니다.

**MCP 서버**: 실시간 시장 데이터를 위한 S&P Capital IQ, Daloopa, Morningstar 연결

**워크플로우**:
- 스킬이 쿼리할 데이터 소스를 식별 (발견)
- MCP 연결이 실시간 재무 데이터를 가져옴
- 스킬이 방법론을 적용하고 출력을 포맷 (조율)
- 스킬이 규정 준수 요구 사항에 대해 검증 (성능)

#### 회의 준비: Notion의 Meeting Intelligence 스킬

회의 준비는 지루합니다. 프로젝트 문서, 이전 회의록, 이해관계자 정보 등 여러 곳에서 컨텍스트를 가져온 다음, 사전 읽기 자료와 안건으로 통합해야 합니다. 매번 다시 설명하게 되는 종류의 다단계 프로세스입니다.

**스킬**: [Meeting Intelligence](https://notiondevs.notion.site/notion-skills-for-claude)는 검색할 페이지, 출력 구조화 방법, 포함할 섹션을 정의합니다

**MCP 서버**: 페이지를 검색, 읽기, 생성하는 Notion 연결

**워크플로우**:
- 스킬이 프로젝트, 이전 회의, 이해관계자 정보를 포함하여 검색할 관련 페이지를 식별 (발견)
- MCP 연결이 Notion에서 콘텐츠를 검색하고 가져옴
- 스킬이 두 문서를 구조화: 내부 사전 읽기 자료와 외부 안건 (조율)
- MCP 연결이 두 문서를 Notion에 저장, 정리 및 연결
- 스킬이 출력이 포맷 표준과 일치하는지 확인 (성능)

## 스킬 vs. MCP 언제 사용해야 하나

스킬과 MCP는 다른 문제를 해결하지만, 특정 워크플로우에 어떤 것을 사용해야 하는지 결정하는 것이 항상 명확하지는 않습니다.

#### 스킬을 사용해야 할 때

스킬은 그렇지 않으면 여러분의 머릿속에 있거나 새로운 팀원이 합류할 때마다 다시 설명하게 되는 지식을 캡처합니다. 다음에 가장 적합합니다:

- **도구를 포함하는 다단계 워크플로우**: 여러 소스에서 가져와 구조화된 문서를 생성하는 회의 준비
- **일관성이 중요한 프로세스**: 매번 동일한 방법론을 따라야 하는 분기별 재무 분석, 필수 체크포인트가 있는 규정 준수 검토
- **캡처하고 공유하고 싶은 도메인 전문 지식**: 연구 방법론, 코드 리뷰 표준, 작성 가이드라인
- **팀원이 떠나도 유지되어야 하는 워크플로우**: 재사용 가능한 지침으로 인코딩된 조직 지식

#### MCP 서버를 사용해야 할 때

MCP는 Claude가 접근하고 사용할 수 있는 것을 확장합니다. 다음이 필요할 때 MCP를 사용하세요:

- **실시간 데이터 접근**: Notion 페이지 검색, Slack 메시지 읽기, 데이터베이스 쿼리
- **외부 시스템에서의 작업**: GitHub 이슈 생성, 프로젝트 관리 도구 업데이트, 알림 전송
- **파일 작업**: Google Drive 읽기/쓰기, 로컬 파일 시스템 접근
- **API 통합**: 네이티브 Claude 지원이 없는 서비스에 연결

무언가를 *하는 방법*을 설명하고 있다면, 그것은 스킬입니다. Claude가 무언가에 *접근*해야 한다면, 그것은 MCP입니다.

#### 간략 참조 표: 스킬과 MCP의 차이점

|  | 스킬 | MCP |
|---|---|---|
| 무엇인가 | 절차적 지식 | 도구 연결 |
| 무엇을 하는가 | Claude에게 무언가를 하는 방법을 가르침 | Claude에게 무언가에 대한 접근 권한을 부여 |
| 언제 로드되는가 | 필요할 때, 관련이 있을 때 | 연결되면 항상 사용 가능 |
| 포함 내용 | 지침, 스크립트, 템플릿, 자산 | 도구, 리소스, 프롬프트 |
| 토큰 동작 | 필요에 따라 로드하여 컨텍스트 보존 | 정의가 미리 로드됨 |
| 적합한 용도 | 워크플로우, 표준, 방법론 | 데이터 접근, API 호출, 외부 작업 |

## 자주 묻는 질문

#### 스킬이 MCP를 대체하나요?

아닙니다. 스킬과 MCP는 다른 문제를 해결합니다. MCP는 외부 도구와 데이터에 대한 연결을 제공합니다. 스킬은 그 연결을 효과적으로 사용하는 방법에 대한 절차적 지식을 제공합니다. 가장 강력한 워크플로우는 둘 다 사용합니다.

#### 하나의 스킬이 여러 MCP 서버를 사용할 수 있나요?

예. 단일 스킬이 한 번에 여러 MCP 서버를 조율할 수 있습니다. 기술 경쟁 분석 스킬은 내부 연구를 위해 Google Drive를 검색하고, GitHub에서 경쟁사 저장소를 가져오고, 웹 검색을 통해 시장 데이터를 수집할 수 있습니다.

#### 하나의 MCP 서버에 여러 스킬을 만들 수 있나요?

예. 스킬은 단일 MCP 연결에서 얻는 가치를 향상시킬 수 있습니다. Notion은 회의 준비, 연구, 지식 캡처, 스펙에서 구현까지 별도의 스킬로 이 패턴을 보여줍니다—[여기](https://claude.com/connectors/notion)에서 확인해 보세요.

## 시작하기

스킬 *그리고* MCP로 구축할 준비가 되셨나요? 시작하는 방법은 다음과 같습니다:

**스킬로:**
- [claude.ai](https://claude.ai)의 설정 → 기능에서 스킬 활성화
- 사전 구축된 예시를 위한 [스킬 라이브러리](https://github.com/anthropics/skills) 둘러보기
- [스킬 문서](https://docs.anthropic.com/en/docs/agents-and-tools/agent-skills) 읽기

**MCP로:**
- 도구용 [MCP 서버](https://github.com/modelcontextprotocol/servers) 둘러보기
- [MCP 문서](https://modelcontextprotocol.io/introduction) 읽기
- [MCP 빠른 시작](https://modelcontextprotocol.io/quickstart)으로 자체 서버 구축

**둘 다 결합:**
- MCP 서버를 연결한 다음, 그것을 사용하는 스킬 추가
